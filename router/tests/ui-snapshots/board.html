API list prices. On a Max plan this tracks how fast you use your limits, not money. Without router means each request on the model and effort it asked for (yours, or the parent chat's for a subagent), with the same tokens. A different effort is priced by its measured cost: a high-effort step costs about 1.4 times a medium one, a low one about 0.72 times. The router's own Haiku calls count as extra. Colors: Haiku green, Sonnet teal, Opus clay, Fable ruby; a darker shade is a higher effort. Cache hit is the share of prompt tokens read from the prompt cache, recorded from version 0.7 on.
